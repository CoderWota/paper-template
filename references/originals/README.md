# Original Documents

Archived source files exactly as received: PDFs, Word files, web captures, datasets, and other formats. One subdirectory per source, named by its stable source ID: `<source-id>/`.

## Rules

- Files here are never edited or replaced after archiving. Interpretation and corrections belong in [`../notes/`](../notes/README.md); readable text belongs in [`../extracted/`](../extracted/README.md).
- Each `<source-id>/` directory has a short README that names the source and how it was obtained. Nothing else is added to the received files.
- Exact duplicates are detected by checksum. A preprint, an accepted manuscript, and a published version are related versions with separate IDs, not merged files.
- A source can be collected, screened out, relevant, or cited without moving its files; its status lives in [`../index.md`](../index.md).

## Who edits what

The agent archives files here during import or download. You do not need to place files here yourself; give the agent the documents, a folder, or a reading list instead.

Whether large originals are kept in version history or backed up separately is a project choice made during setup.
