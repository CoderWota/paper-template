# Privacy and Processing Requirements

This file records confirmed choices about document processing, external query sharing, and data-use requirements. Document upload permission and search-query permission are separate scopes.

## MinerU document processing

<!-- mineru-scope: references-only -->

- Rule: Use MinerU remotely through the official cloud MCP. Only reference materials may be uploaded to mineru.net. Manuscripts and drafts, editor or reviewer correspondence, collaborator feedback, and other materials are outside this scope. No local MinerU inference is used.
- Scope: MinerU processing in this workspace, in both clients and workspace scripts. The material must be identified as a reference source before it is sent.
- Confirmed: 2026-10-31; "We will not run MinerU locally; send processing remotely." "Remote processing does not authorize uploading all materials. Only reference materials may be uploaded."

## Search queries

No standing Sciverse or other external search-query scope has been confirmed. A prior one-time service test does not grant continuing query permission.
