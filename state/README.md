# Project State

A concise handoff between sessions: what is in progress, what is blocked, and the next useful action. Any agent session can start here instead of asking you to reconstruct earlier work.

## Contents

- [`current.md`](current.md): the single current status, with the active objective, work in progress, open questions for you, and the next step.

## Rules

- Keep it short and current. Replace outdated entries instead of appending history.
- It is not a chat transcript, a rule book, or a place for preferences the agent has inferred. Confirmed rules go in [`requirements/`](../requirements/README.md).

## Who edits what

The agent updates this file when work remains unfinished. You can read it to see where things stand; you do not need to edit it.
