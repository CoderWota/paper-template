# Manuscript Audit

Reviews the manuscript critically: the argument, whether each claim is supported by the cited sources or the project's results, contradictions between sections, terminology, your confirmed writing rules, language, the workspace conventions, and known limits of the target venue.

Ask, for example: "Audit the results and discussion sections and tell me which claims need evidence."

## What to expect

- Findings are prioritized and point to exact passages, with the evidence or rule behind each.
- A citation that exists is not treated as proof that it supports the claim; both are checked separately.
- The text is not changed unless you ask. The report is kept in `outputs/checks/` with the inputs it examined, so a later change to those inputs marks it as out of date.
