# Outputs

Formatted manuscripts and submission packages produced from the working text. Outputs are generated from [`manuscript/`](../manuscript/README.md) with an output profile from [`requirements/profiles/`](../requirements/profiles/README.md). Edit the manuscript, not the outputs.

## Contents

- [`preview/`](preview/README.md): rebuildable drafts for checking, not kept in version history.
- [`releases/`](releases/README.md): preserved packages, frozen once created.

A successful export is not proof of format compliance or submission readiness. Each output comes with a short summary of the profile applied, the checks that passed, and what still needs attention.

Edits made in a generated Word file are not copied back into the manuscript automatically; ask the agent to reconcile them.

Related skills: `submission-assembly`, `submission-readiness`.
