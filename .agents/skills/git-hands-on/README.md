# Git Hands-On

A guided, practical introduction to version control for people who do not know Git. The agent operates Git; you decide what to keep and see the result of every step.

Ask, for example: "I do not know Git. Help me save versions of this paper, see what changed, and practice recovering an earlier version."

## What to expect

- You first practice on a separate practice copy, so nothing can happen to your paper while you learn.
- Then the same actions are applied to your real work when you ask: saving a version, comparing versions, and retrieving earlier text.
- No commands to memorize and no branch lessons; a copy outside your computer is made only when you ask.

The agent instructions are in [SKILL.md](SKILL.md). It uses `git-inspection`, `git-setup`, `git-save`, `git-compare`, `git-recovery`, and `git-backup`.
