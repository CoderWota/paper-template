# Agent Resources

Shared resources for AI agents working in this workspace, independent of any one agent application. Codex discovers repository skills here; Claude Code uses generated copies in [`.claude/`](../.claude/README.md).

## Contents

- [`skills/`](skills/README.md): the canonical skill packages. Each skill is written once, here.

## Who edits what

The agent and the template maintainer maintain this directory. Researchers do not need to open or edit it; describe the task you want in ordinary language instead.

The operating contract that applies to every task is [`AGENTS.md`](../AGENTS.md) at the workspace root.
