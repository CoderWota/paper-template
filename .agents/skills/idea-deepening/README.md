# Idea Deepening

Examines an idea or research question with you, one focused question at a time, in the spirit of grilling: what exactly is asked, what the contribution is, which assumptions it rests on, how it differs from the nearest prior work, which rival explanations exist, whether it is feasible, and what the next check is.

Ask, for example: "Examine this idea with me, one question at a time, and tell me where it is weak."

## What to expect

- Each question explains why it matters and comes with the agent's recommendation. The agent looks up what the workspace or an authorized search can answer instead of asking you.
- Novelty, significance, feasibility, and support are assessed separately; originality stays preliminary when the search was limited.
- The interview stops when a useful next action is clear. A retained idea's note is updated with what you settled.
