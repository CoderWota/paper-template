# Git Recovery

Brings back earlier material: a deleted paragraph, an older version of a section, or a whole earlier file or folder.

Ask, for example: "Bring back the paragraph about the pilot study that I deleted last week."

## What to expect

- By default the agent retrieves the earlier material as a separate copy and shows it to you; your current files stay as they are.
- Replacing current files with an earlier version happens only when you choose it, and the current content is kept first, so you can return to it.
- History is never rewritten or deleted.

The agent instructions are in [SKILL.md](SKILL.md). Related skills: `git-compare`, `git-save`, `manuscript-writing`.
