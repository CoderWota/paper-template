# Git Inspection

Tells you, in plain words, what version history this workspace has: whether your work is saved, what changed since the last saved version, whether any copy exists outside this computer, and whether the copy carries history from the template or from another paper. It changes nothing.

Ask, for example: "Is my work saved?" or "What versions of this paper exist?"

The agent instructions are in [SKILL.md](SKILL.md). The skill uses `scripts/versions.py`. Related skills: `git-setup`, `git-save`, `git-backup`, `git-hands-on`.
