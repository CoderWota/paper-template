# Manuscript Assets

Figures, tables, and other non-text material used in the manuscript, with their captions, stable identifiers, and source or permission notes where relevant.

## Rules

- Each figure and table has a stable identifier used for cross-references, so renumbering never breaks a reference.
- Keep the editable source: the data or code that generates a plot, or the Mermaid source of a diagram. Rendered diagram images are derived copies, not separately maintained figures.
- Scientific plots, photographs, and images taken from sources keep their original or plotting formats.
- Record where material from other works came from, with any permission notes.

## Who edits what

You can add figures, data, or images here, or give them to the agent. The agent organizes the files, captions, identifiers, and source notes, and renders diagram figures for outputs.
