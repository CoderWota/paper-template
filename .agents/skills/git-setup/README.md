# Git Setup

Prepares or repairs the local version history of the workspace when you want one: installs Git with your consent if it is missing, creates the history, agrees with you on what it tracks, and keeps passwords and keys out of it. It also arranges history that came with a copied workspace, such as the template's own history or a link back to the template's repository, and repairs problems such as a tracked secret, always after explaining the choices.

Ask, for example: "Set up version history for this paper."

## What to expect

- Nothing is created or changed before you choose, and nothing is sent anywhere.
- Existing history is kept; nothing is deleted or rewritten.
- You never need to edit Git settings yourself.

The agent instructions are in [SKILL.md](SKILL.md). Related skills: `git-inspection`, `git-save`, `environment-management`.
