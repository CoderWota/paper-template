# Previews

Rebuildable outputs for reviewing the current manuscript: draft Word, PDF, or other files built with an output profile. Everything here except this README is excluded from version history and can be deleted and rebuilt at any time.

A preview reflects the manuscript at the time it was built. After the manuscript or the profile changes, rebuild it; an older preview is not evidence that the current text passes its checks.

Ask the agent, for example: "Build a preview with the journal profile and tell me what still fails."
