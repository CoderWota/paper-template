# Git Compare

Compares the current text with an earlier version, or two saved versions with each other, and explains what changed in research terms: claims, sections, citations, figures, and wording, with their locations.

Ask, for example: "What changed in the methods section since last week?" or "Compare this draft with the version I sent to my supervisor."

The comparison changes nothing. The agent instructions are in [SKILL.md](SKILL.md). Related skills: `git-save`, `git-recovery`, `git-hands-on`.
