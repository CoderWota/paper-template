# Source Notes

Interpretation and evidence notes, one Markdown file per source: `<source-id>.md`. A note says what a source actually supports, where, and within what limits. Notes are kept apart from the extracted text so that a summary is never mistaken for the source itself.

## A note records

- Supporting passages with evidence locators: page, section, figure, or table. PDF page index and printed page label are distinguished, and a missing locator is never invented.
- Scope, limitations, and contradictions with other sources.
- Verification status, for example abstract only, extraction checked, or verified against the original.

An abstract-only note cannot support claims about the full text. A citation that resolves is not proof that the source supports a claim.

## Who edits what

You can write or correct notes directly. The agent creates and updates notes when it reads sources for you, and keeps your additions when it updates them.

Example request: "Compare what these sources actually support and explain where they disagree."

Related skill: `literature-and-evidence`.
