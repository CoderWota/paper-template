# Git Save

Saves the current state of your work as a version on this computer, with a short description of what changed, so that you can compare or retrieve it later.

Ask, for example: "Save this version before I restructure the paper," or "Save the revised introduction."

## What to expect

- The agent shows what has changed and agrees with you on what the version includes.
- Files that look like passwords or keys, and very large files, are not saved without your decision.
- A saved version stays on this computer; making a copy elsewhere is a separate request.

The agent instructions are in [SKILL.md](SKILL.md). Related skills: `git-compare`, `git-recovery`, `git-backup`.
