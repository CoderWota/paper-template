# Git Backup

Makes a copy of your saved versions outside this computer, for example in a private online repository, on an institutional server, or on an external drive, and checks that the copy holds your latest version.

Ask, for example: "Back up this paper to my private GitHub repository," or "Is my work backed up anywhere?"

## What to expect

- The agent first explains what would leave your computer and asks where the copy goes, who can see it, and what it may contain. The destination is recorded with your words in `requirements/privacy.md`, and nothing is copied anywhere else.
- Signing in to a service or creating an account is your own step; you never share a password with the agent.
- Nothing is published or made public unless you explicitly ask for it, and the template's own repository is never used.

The agent instructions are in [SKILL.md](SKILL.md). Related skills: `git-inspection`, `git-save`, `privacy-configuration`.
