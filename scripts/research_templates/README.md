# Research Script Templates

Text files that `scripts/research.py` fills in and writes into the researcher's project: the list of code repositories in `code/README.md`, the ignore rules for an attached repository, the Claude Code exclusions, the local `CLAUDE.md`, and the commit message of an import. A `${name}` marks a value that the script supplies. Change the wording here instead of in the Python code, and keep each file's placeholders as they are.
